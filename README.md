# MTH File Manager

Aplicativo Android de gerenciamento de arquivos, desenvolvido em Kotlin com Jetpack Compose e Material 3.

## Tecnologias
- Kotlin 2.0.21
- Jetpack Compose + Material 3
- Android Gradle Plugin 8.7.3
- Arquitetura inicial preparada para evolução em MVVM

## Requisitos
- Android Studio atualizado
- JDK 17
- Android SDK 35

## Abrir o projeto
1. Clone este repositório.
2. Abra a pasta raiz no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute o módulo `app em um dispositivo ou emulador.

> A primeira entrega contém a base visual e a configuração do aplicativo. As operações reais de arquivos, permissões de armazenamento, cartão SD, ZIP, lixeira e análise serão implementadas nas próximas etapas.
